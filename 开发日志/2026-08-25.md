## 使用说明
### 多设备同步步骤：
1. 在 GitHub 生成 PAT：Settings → Developer settings → Personal access tokens → Tokens (classic)
2. 勾选 `gist` 权限，生成 token
3. 在登录页面粘贴 token，点击"连接"
4. 登录/注册后，数据会自动同步到云端
5. 在其他设备登录时，输入相同的密码和 token，数据会自动合并
